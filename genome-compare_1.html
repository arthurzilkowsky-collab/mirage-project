Genome Compare

Load two sequences (gene-scale, up to ~50kb each). Both get divided into the same number of proportional windows and scored for repeat structure, so you can scan the two side by side — then click any window to zoom into the actual mirror-grouped bases, and hear both at once, A panned left, B panned right.

This compares structural repeat profiles, not sequence identity — it isn't an alignment tool (no BLAST-style homology matching). Windows are matched by proportional position, not by matching bases.

Matched blocks — shared "Lego" groups between A and B

Every mirror group that appears in both sequences becomes a candidate landmark. Candidates are kept only if they can be chained into a consistent, non-crossing order — the same basic idea genome aligners like MUMmer use, just built from mirror groups instead of arbitrary substrings. This is a heuristic landmark map, not a formal sequence alignment.

Known functions — match against sequences you supply

Paste short reference sequences (FASTA-style: >name then sequence) — motifs, known genes, anything you already have identified. This checks both strands (forward and reverse complement) for exact matches. It does not query any external database.

Remainders — the gaps between matched blocks

Whatever falls between (or outside) the matched Lego blocks, with no exact known-function hit inside it either. These are the parts of each sequence that neither structural matching nor your known-function library currently explains — not necessarily meaningless, just unaccounted for so far.
